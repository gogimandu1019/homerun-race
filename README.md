# ⚾ 홈런레이스

**타이밍 맞춰 담장을 넘기는 웹 야구 게임**

👉 **지금 플레이하기: https://homerunracegame.com/**

날아오는 공에 맞춰 화면을 클릭(모바일은 탭)해 스윙하고, 15구 동안 홈런 비거리로 점수를 겨루는 게임입니다.
설치나 회원가입 없이 PC와 모바일 브라우저에서 바로 즐길 수 있습니다.

---

## 게임 방법

1. 시작 화면에서 **닉네임**, **난이도**, **응원 팀(유니폼)** 을 고릅니다.
2. 투수가 공을 던지면, 공이 홈플레이트에 들어오는 순간에 맞춰 **클릭 / 탭 / 스페이스바**로 스윙합니다.
3. 15구를 모두 치면 결과가 나오고, 기록을 랭킹에 올릴 수 있습니다.

### 타이밍 판정

| 판정 | 결과 |
|---|---|
| **PERFECT** | 무조건 홈런 |
| **GOOD** | 잘 맞은 타구. 펜스를 넘길 가능성이 높음 |
| 그 외 | 빗맞거나 헛스윙 |

- 일찍 치면 왼쪽, 늦게 치면 오른쪽으로 날아갑니다. 너무 빗나가면 파울입니다.

### 점수

- 홈런이면 **비거리(m) × 100점**, 홈런이 아니면 0점
- 15구 중 무작위 **5구는 점수 2배** 이벤트
- 구장은 파울라인 100m, 가운데 122m의 둥근 펜스(높이 3.6m)

## 모드

| | 이지 | 하드 | 익스트림 |
|---|---|---|---|
| 구속 | 115~140km/h | 130~155km/h | 145~165km/h |
| PERFECT 판정 범위 | ±30ms | ±14ms | ±9ms |
| GOOD 판정 범위 | ±70ms | ±38ms | ±25ms |
| 공이 보이는 속도 | 느리게 | 더 빠르게 | 가장 빠르게 |

### 무한 모드

- 공 개수 제한 없이 **아웃 3개**가 될 때까지 칩니다. 홈런이 아니면 모두 아웃입니다.
- 이지 수준으로 시작해 **홈런 5개마다 레벨업**, 공이 빨라지고 판정이 좁아집니다. 홈런 30개부터는 익스트림 수준입니다.
- 2배 이벤트는 없고, 랭킹은 **홈런 수 → 최장 비거리** 순입니다.

랭킹은 모드마다 **따로** 집계됩니다.

## 팀과 유니폼

10개 팀 중 하나를 골라 그 팀 유니폼을 입고 칩니다. 등번호는 팀 기본 번호를 쓰거나 0~99 사이로 직접 정할 수 있습니다.

수원 마법사 · 대구 사자 · 광주 호랑이 · 서울 쌍둥이 · 서울 곰돌이 ·
인천 강아지 · 부산 갈매기 · 창원 공룡 · 대전 독수리 · 서울 영웅

> 팀 이름과 디자인은 게임용 창작이며, 실제 프로야구 구단·리그와는 관련이 없습니다.

## 랭킹

게임이 끝나면 닉네임으로 기록을 저장할 수 있고, 세 가지 순위표가 있습니다.

- **점수**: 한 경기 총점 순위 (무한 모드는 **홈런**: 홈런 수 → 최장 비거리 순)
- **비거리**: 한 경기에서 가장 멀리 친 홈런 순위
- **팀**: 팀별 점수 합계 순위(무한 모드는 홈런 합계). 내 기록이 응원 팀 점수에 더해집니다.

## AI 앱에서 랭킹 보기 (MCP)

Claude 같은 AI 앱에 아래 주소를 추가하면, 대화하면서 홈런레이스 랭킹을 물어볼 수 있습니다.

```
https://homerunracegame.com/api/mcp
```

- **Claude (웹·데스크톱)**: 설정 → 커넥터 → 커스텀 커넥터 추가 → 위 주소 입력
- **Claude Code**: `claude mcp add --transport http homerun-race https://homerunracegame.com/api/mcp`

예시 질문: "홈런레이스 무한 모드 1위 누구야?", "하드 모드 팀 순위 알려줘", "감자 닉네임 기록 찾아줘"

| 도구 | 하는 일 |
|---|---|
| `get_leaderboard` | 모드별 랭킹 (점수·비거리·홈런 수 순) |
| `get_team_standings` | 모드별 팀 순위 |
| `get_player_records` | 닉네임으로 모드별 최고 기록 찾기 |
| `get_game_info` | 게임 규칙과 모드 안내 |

**조회만 가능**하며, 기록을 저장하거나 바꾸는 기능은 없습니다. 로그인도 필요 없습니다.

## 기술 구성

| 부분 | 사용한 것 |
|---|---|
| 게임 화면 | HTML · CSS · JavaScript 한 파일 (`index.html`), Canvas로 그림 |
| 랭킹 API | Vercel 서버리스 함수 (`api/scores.js`) |
| MCP 서버 | Vercel 서버리스 함수 (`api/mcp.js`), Streamable HTTP · JSON 응답 · 상태 없음 |
| 데이터베이스 | Supabase (`scores` 테이블, `team_standings` 뷰) |
| 호스팅 | Vercel |

```
index.html            게임
guide.html            게임 방법 페이지
privacy.html          개인정보처리방침
api/scores.js         랭킹 조회(GET) / 기록 저장(POST)
api/mcp.js            AI 앱용 MCP 서버 (조회 전용)
lib/supabase.js       Supabase 연결 공용 코드
supabase/*.sql        데이터베이스 테이블·뷰 생성 SQL
scripts/              로컬 미리보기 서버
```

### 직접 띄워 보려면

1. Supabase 프로젝트를 만들고 SQL Editor에서 `supabase/schema.sql`을 실행합니다.
   (기존 테이블이 있으면 `002`~`005` SQL을 순서대로 실행)
2. Vercel에 이 저장소를 연결하고 환경변수 두 개를 넣습니다. 목록은 `.env.example`에 있습니다.
   - `SUPABASE_URL`: Supabase Project URL
   - `SUPABASE_SERVICE_ROLE_KEY`: Supabase secret 키 (`sb_secret_…`). 브라우저 코드나 Git에 넣지 마세요.
3. 배포하면 끝입니다. 로컬에서는 `vercel dev`로 실행할 수 있습니다.

### 보안

- 데이터베이스는 브라우저에서 직접 접근할 수 없고, `/api/scores`만 서버 키로 읽고 씁니다.
- 서버에서 닉네임 길이(1~12자), 모드별 점수·홈런 수 범위, 비거리(0~200m)를 검사하고, 점수가 홈런 수·최장 비거리와 맞는지도 확인합니다.
